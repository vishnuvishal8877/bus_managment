## 📖 About The Project
**BusGo** is designed to simplify public transport operations and ticket reservations. It allows administrators to publish new bus routes and passengers to explore available buses, check dynamic seat availability, view fares, and book tickets in real-time. All data is securely persisted using the browser's `localStorage`.

---

## ✨ Key Features
- **Explore Buses:** View live routes (Source to Destination), ticket fares, and real-time seat availability.
- **Add New Bus (Admin Panel):** Add new bus numbers, routes, total seats, and ticket pricing with instant validation.
- **Ticket Booking System:** Book seats dynamically with passenger verification and auto-deduction of available seat counts.
- **Local Storage Persistence:** Retains data even after page refreshes without needing a complex external database.
- **Modern UI/UX:** Built with CSS gradients, card layouts, smooth tab transitions, and custom scrollbars.
